# Daily QOTD requirement

The user's standing requirement is automatic daily Question of the Day practice, even when they forget to open the dashboard.

- Complete the user's entire configured daily allotment (currently two), with QOTD included in that count and attempted first, for the signed-in account and local date.
- Learning mode and review mode must not turn any automatic daily allotted question into an unsubmitted draft. Review mode applies only to manual work.
- Never mark an automatic daily session completed without accepted judge results for the full allotted count and QOTD.
- Increasing the daily allotment must retain already accepted questions and resume the remaining work; it must not silently postpone the added questions until tomorrow.
- Preserve scheduled retries, account isolation, explicit Stop/pause controls, provider budgets, contest pauses, and judged-submission limits. Report blockers honestly; never promise acceptance regardless of service availability.
- Keep regression tests for these requirements when changing scheduling, discovery, review, or submission code.
