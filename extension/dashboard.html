Allowed difficulties:

Question count applies to automatic sessions. Manual Prepare uses the custom count on the Today page (1–100). Solutions are submitted on the currently signed-in LeetCode account. To protect accuracy, each question gets at most two judged submissions per day; repeated code and uncertain submissions pause for review.

Run while this Mac is sleeping

For automatic connection and login startup, double-click Start Practice Ex.command in the project folder. This setup does not need an administrator password.

macOS setup wakes the computer five minutes before daily practice, each needed retry, and official contests. Keep the browser with Practice Ex. open before sleep. Reinstall the helper only when its code changes.

npm run background:install
This requires the Mac administrator password. It wakes from sleep; it cannot run while fully powered off.

Protect daily completion

The full allotted count and QOTD remain mandatory. Optional work waits when the daily allowance is needed.

Local AI: Ollama or LM Studio

No models are downloaded automatically. Local inference uses your Mac. Cloud fallback sends problem data to your configured cloud provider. With fallback off, an unavailable local model can block daily work. Disabling Local AI restores normal cloud routing.

Practice and spending controls

Enter prices for the selected models. A daily cost limit requires known prices for the provider being called. Additional cases are generated suggestions; passing them cannot prove hidden-test correctness.

Backups and diagnostics

Exports omit provider keys, login cookies and connection tokens. Restoring merges history, keeps current credentials and pauses Auto Mode. Diagnostic reports also omit account names, statements and source code.

Safe updates and rollback

Select a release you trust. Compatibility is checked before installation. Updates restart the server and preserve runtime data.
